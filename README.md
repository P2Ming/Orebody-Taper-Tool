# Orebody Taper Tool · GOCAD TSurf 矿体自动尖灭工具

本地可视化应用。导入单个 `.ts` 文件，自动识别其中多个 GOCAD TSurf 和 TFACE Part，分别追加两端尖灭网格，再导出为一个新的 TSurf 文件。无需拆分输入文件，数据不上传服务器。

## 启动

需要 **Node.js 18 或以上**。Windows 双击 **Start.cmd**，浏览器自动打开。保持启动窗口开启，结束时按 `Ctrl+C`。

也可在本目录执行：

```sh
npm start
```

没有需要安装的 npm 包；Three.js 已附在 `vendor/`。首次下载完成后可断网运行。服务只监听本机 `127.0.0.1`，默认端口 4173；端口占用时自动尝试后续端口。直接双击 index.html 无法启动 ES modules / Web Worker，请使用启动脚本。

## 使用

1. 启动时显示内置**合成示例**，包含 2 个 TSurf、3 个 Part。它不代表真实矿区数据。点击导入区域或拖入实际 `.ts` 文件替换。
2. 在“当前模型 / Part”下拉框选择要查看的 Part。文件中的 TSurf 和各个 TFACE 会自动列出。
3. 每个可处理 Part 默认加入批量尖灭。设置 A / B 端长度、渐缩环数、渐缩指数；切换 Part 后参数独立保留。
4. 直接拖动三维视图中的 A / B 尖点即可实时重建渐缩网格，同时同步长度。拖动在与屏幕平行、经过尖点的平面内进行；旋转视角后可调整其他方向。尖点必须保持在原始端部的向外半空间，不能穿入主体。松开鼠标后自动检查拓扑，随后恢复导出；按 Esc 取消本次拖动。输入框 / 滑杆修改仍可点击“生成 / 更新尖灭预览”。
5. 拖动端点塑形；三维视图空白处左键旋转、右键平移、滚轮缩放；`F` 适配视图。可切换原始 / 尖灭结果、网格线以及全部 Part 叠加显示。
6. 取消勾选的 Part 原样保留。点击“导出 TSurf”，下载 `原文件名_tapered.ts`；同一文件内所有 TSurf / Part 均保留。浏览器普通下载不具有原输入文件的写权限。
7. 页面保留封闭与拓扑状态卡。异常原因在状态卡和提示中显示；处理报告区域与 JSON 下载入口已移除。

导入默认 UTF-8；GBK 等传统中文文件可点击左下帮助按钮，将“下次导入编码”改为 GB18030 后再导入。输出统一为 UTF-8，保留原文件 BOM 有无与换行风格。

## 自动处理与算法

- 对三角形建立无向边使用关系，提取只被一个三角形使用的边；边界顶点度数必须为 2，并按照原三角形方向追踪两个简单边界环。
- 每个处理 Part 必须是一个连通主体；开放边界环必须恰好为两个。已闭合 Part 自动保持原状；其他异常 Part 在拓扑状态卡中提示并默认不处理。
- 以每个边界环顶点均值作为端部中心，沿拓扑邻接逐层寻找内部断面中心，由“内部中心 → 端部中心”估计局部向外方向。无法取得内部断面时使用另一端中心作为回退估计，可在三维视图中进一步拖动修正。
- A / B 按原坐标系下端部中心的 X、Y、Z 排序；A 不一定是地理意义上的西端。坐标及长度保持原单位，不执行投影、单位转换。
- N 个新增环位于 `t = k / (N+1)`，其中 `k = 1…N`。每环中心从原始端部中心向当前尖点移动 `t` 倍位移，边界顶点相对端中心的偏移乘以 `(1−t)^p`。
- 相邻环以三角形带连接，最后一环连接独立尖端。新增面在接缝处使用与原开放边相反的方向，保留原始主体的全部顶点坐标及三角形绕序。
- 拖动时使用 Web Worker 合并过时的鼠标更新，仅生成当前 Part 的网格；松开后对所有待处理 Part 重新完整校验。实际刷新速度取决于模型大小与设备性能。
- 每个 TSurf 对象内统一分配新编号，避免多个 TFACE 批量处理后编号冲突。
- 支持 `VRTX`、`PVRTX`、`ATOM` 和 `TRGL`。手动拖动后的尖点位置按 Part 独立保存并参与批量导出，重置会恢复自动方向。输入长度时，已拖动端点沿当前方向伸缩。新增环复制对应原边界顶点的属性值，尖端对有效数值求均值，存在 NO_DATA 时使用 NO_DATA。分类或离散属性如不适合均值，应在导出后按项目规则审核。
- 原始记录按原顺序保留；只在对应 Part 最后一个网格记录后插入新增顶点和面。保留原始 HEADER、坐标系、属性声明等内容。
- 网格计算、文件输出使用双精度；三维显示先减去局部坐标中心，再转换为 GPU 浮点，避免大地坐标显示抖动。按 ZPOSITIVE 的 Elevation / Depth 显示竖向。

## 检查范围和适用限制

检查缺失顶点、重复顶点编号、退化面、重复面、非流形边、非流形顶点、绕序冲突、边界分叉、连通分量、开放边数及 Euler 特征。处理后要求闭合，且 Euler 特征比原侧面增加 2。原始闭合 Part 不自动重建。

**拓扑闭合不保证没有几何自交。此版本不执行三角形自交或不同 Part 之间的碰撞检测。** 极弯曲、截面凹陷、切口严重不规则、延伸方向相交的模型，应结合三维预览审核。算法不移动主体网格，也不自动修复原始错误网格。

输入上限为 150 MB；每个 Part 新增顶点上限为 200 万。界面支持 1–64 环、0.2–5 渐缩指数；核心 API 支持至 128 环。过高指数、过多环或过短长度会产生接近零面积的三角形，检查失败时请调小指数 / 环数或增加长度。文件和界面状态只保留在当前网页内，刷新后恢复合成示例。

未提供实际矿体文件，因此已完成的验证基于合成样例与异常网格测试；尚未针对用户实际地质数据或特定 GOCAD 版本做导入验收。

## 验证与开发

```sh
npm test
```

自动测试覆盖多 TSurf / TFACE、两端闭合、原始网格保持、独立参数、跳过 Part、ATOM、正反绕序、BOM / CRLF、大坐标双精度、PVRTX 属性、导出回读、拖动尖点位置与方向保持、实时预览与校验网格一致性，以及各类异常网格与参数拒绝。

源码说明：

- `core.mjs`：解析、拓扑分析、端部估计、网格构建、导出。
- `worker.mjs`：在 Web Worker 中计算网格，避免阻塞界面。
- `viewer.mjs`：Three.js 三维视图及 OrbitControls。
- `app.mjs`：导入、Part 状态、参数、预览与批量导出交互。
- `server.mjs`：无需依赖的本地静态服务器。
- `examples/`：原始合成样例、全 Part 尖灭结果和浏览器导出验证样例。
